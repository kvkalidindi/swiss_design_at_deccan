# Microsoft Office Artifacts

Generated by `scripts/_09_emit_office.py` from the Plan 1 palette + fonts + logo.

## What's here

- `office-theme.thmx` — Office theme with Deccan colors and IBM Plex Sans typography
- `templates/deccan.dotx` — Word template (cover page, branded styles, header/footer)
- `templates/deccan.potx` — PowerPoint template (title slide, content layouts, brand colors)
- `templates/deccan.xltx` — Excel template (title row, table styles, banded data rows)
- `templates/signature.htm` — Outlook email signature (logo + IBM Plex Sans + brand colors)

## Per-user install (Windows PowerShell)

**Recommended:** run the bundled installer.

```powershell
.\install.ps1
```

This copies the theme + 3 templates to `%APPDATA%\Microsoft\Templates\` and sets the `PersonalTemplates` registry key for Word, PowerPoint, and Excel (Office 365 won't show the **Personal** tab in `File → New` until that key is set — copying files alone is not enough).

To uninstall:

```powershell
.\install.ps1 -Uninstall
```

After install, **close and reopen any running Office apps** (settings are read at startup), then:

- Theme appears in **Design → Themes → Custom**
- Templates appear in **File → New → Personal**

### Manual install (if you don't want to run the script)

```powershell
$Templates = "$env:APPDATA\Microsoft\Templates"
$Themes = "$env:APPDATA\Microsoft\Templates\Document Themes"
if (-not (Test-Path $Themes)) { New-Item -ItemType Directory -Path $Themes -Force | Out-Null }

$root = "C:\path\to\swiss_design_at_deccan\office"
Copy-Item "$root\office-theme.thmx" -Destination $Themes -Force
Copy-Item "$root\templates\deccan.dotx" -Destination $Templates -Force
Copy-Item "$root\templates\deccan.potx" -Destination $Templates -Force
Copy-Item "$root\templates\deccan.xltx" -Destination $Templates -Force

# Required for Office 2013+ to discover personal templates
@("Word","PowerPoint","Excel") | ForEach-Object {
    $key = "HKCU:\Software\Microsoft\Office\16.0\$_\Options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
    New-ItemProperty -Path $key -Name "PersonalTemplates" `
        -Value $Templates -PropertyType ExpandString -Force | Out-Null
}
```

## Outlook signature

1. Open Outlook → File → Options → Mail → Signatures
2. Click `New`, name the signature `Deccan`
3. Open `templates/signature.htm` in a browser, select all (Ctrl+A), copy (Ctrl+C)
4. Paste into the Outlook signature editor
5. Set as default for new messages and replies/forwards
6. Replace placeholders ([Your Name], [Your Role], etc.) with your details

## Fonts required

The templates reference IBM Plex Sans and IBM Plex Mono. For correct rendering, install these fonts at the OS level. The `fonts/` directory at the project root contains the TTF files:

```powershell
Get-ChildItem "C:\path\to\swiss_design_at_deccan\fonts" -Recurse -Filter *.ttf |
    ForEach-Object { Start-Process $_.FullName }
```

Each TTF opens the Windows font preview; click `Install`.

(Plan 5 will automate font installation via Group Policy / Intune for corporate fleets.)

## Regenerating

If the Plan 1 palette changes, re-run the emitter:

```powershell
python scripts\_09_emit_office.py
```

This regenerates all 5 artifacts in place. Idempotent: re-running with no input changes produces functionally identical output.
